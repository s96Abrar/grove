# Getting help

- **How do I…?** Start with the [User guide](docs/USER-GUIDE.md). The Help tab in Grove's Settings lists keyboard shortcuts.
- **Something isn't working.** Check [Troubleshooting](docs/DEVELOPMENT.md#troubleshooting) and [Terminal compatibility](docs/TERMINAL-COMPATIBILITY.md), then open a bug report with the issue form.
- **Is feature X planned?** See the [feature matrix](docs/FEATURE-PARITY.md), then open a feature request if it isn't listed.
- **Security problem?** Do not open an issue. Follow the [Security policy](SECURITY.md).

Grove is a small project maintained in spare time, so there is no guaranteed response time. Coding agents, `gh`, tmux and Git are separate tools; questions about installing or signing in to them belong with those projects.
